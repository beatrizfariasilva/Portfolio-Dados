## Projetos

### 📈 [Analise_Stockwise](https://github.com/beatrizfariasilva/Analise_Stockwise)

Este projeto realiza uma análise detalhada de ativos do mercado financeiro, focando em tendências de preços e indicadores de performance para auxílio em investimentos.

*   **Problema de Negócio:** Identificar padrões em séries temporais de ações para prever movimentações futuras.
*   **Ferramentas Utilizadas:** Python, Pandas para manipulação de dados e bibliotecas de visualização para gerar gráficos de candlestick e tendências.
